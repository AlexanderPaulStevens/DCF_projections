# DCF Frontend

React frontend for DCF Projections application.

## 🚀 Quick Start

### Deploy to Cloud Run
```bash
./deploy.sh
```

### Local Development
```bash
# Install dependencies
npm install

# Run locally
npm start
```

## 🎨 Features

- Company search and analysis
- Interactive stock charts with forecast data
- DCF analysis and sensitivity analysis
- Competitive analysis
- Technical analysis
- Responsive design
